# Roadmap — MAT Fácil

## Concluído ✅

### v0.1.0
- Projeto inicial com Next.js 16, React 19, TailwindCSS v4
- Autenticação completa (login, cadastro, recuperação)
- Dashboard do aluno
- Matérias, assuntos e aulas
- Sistema de gamificação (10 níveis, XP)
- Painel admin com CRUD
- Ranking de alunos
- Schema SQL com RLS

### v0.2.0
- Dark theme completo
- Fontes Inter + Space Grotesk

### v0.3.0
- Campo série no cadastro e perfil
- Série associada a assuntos (filtro admin)
- Página de perfil do aluno
- Página admin de alunos (filtro por série)
- Canvas interativo (área de formas irregulares)
- Dockerfile e Docker Compose para VPS
- Documentação completa
